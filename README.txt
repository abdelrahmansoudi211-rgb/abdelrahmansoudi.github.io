# Abdelrahman Soudi Portfolio

A responsive personal portfolio website built from the information in Abdelrahman Soudi's CV.

## Files
- `index.html` — main website
- `style.css` — responsive design
- `script.js` — small mobile navigation behavior
- `Abdelrahman-Soudi-CV.pdf` — CV linked from the Resume button

## Publish on GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a new **public** repository named exactly:
   `YOURUSERNAME.github.io`
3. Upload all files in this folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
6. Save. Your website will normally be available at:
   `https://YOURUSERNAME.github.io/`

## Important
Replace `YOURUSERNAME` with your GitHub username. The website already contains the contact details and LinkedIn URL from the CV, while the date of birth was intentionally not placed on the public website.
